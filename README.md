# Trigonometría desde cero · Capítulo 4

Una clase continua y explicada paso a paso para quien empieza de cero. Cubre los módulos 4.1 a 4.5:

| Lección | Módulo | Tema |
|---|---|---|
| 0 | — | Herramientas: triángulo rectángulo, Pitágoras, raíces |
| 1 | 4.1 | Ángulos, radianes y razones trigonométricas |
| 2 | 4.2 | Del triángulo al círculo: funciones de cualquier ángulo |
| 3 | 4.3 | Identidades |
| 4 | 4.4 | Gráficas: amplitud, período y desfase |
| 5 | 4.5 | Ecuaciones trigonométricas |

Cada lección empieza conectando con la anterior y termina anticipando la siguiente.

## Cómo abrirla

El repositorio es privado, así que GitHub no la muestra como página web. Para verla:

1. Pulsa **Code → Download ZIP** (o descarga solo `index.html`).
2. Abre `index.html` con tu navegador (Chrome, Edge o Safari), con internet para que se vean las fórmulas.

## Qué trae

- Recuadros **¿Por qué?**, **Clave**, **Cuidado** y **Conexión** en cada tema.
- Ejemplos resueltos paso a paso y preguntas de **Compruébalo** con respuesta oculta.
- Tres herramientas interactivas: círculo unitario, comprobación de sen² + cos² = 1 y una onda con controles para *a*, *d* y *h*.
- Botón **🔊 Escuchar** (voz del navegador) y botón **💬 Preguntar al tutor**, que abre el tutor de Claude en claude.ai.
